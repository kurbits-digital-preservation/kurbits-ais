# V 1.1.4 (2026-xx-xx)

# Changelog

## Added
- Added CSV export (Excel-compatible: UTF-8 BOM, semicolon delimiter, CRLF)
- Export formats can now use a Python builder as an alternative to a Jinja template

## Fixed

- Search: agent links are now inherited by descendant records, so the agent filter and facet include everything under a linked fonds or series. Agent type facets only appear when agents are searched.
- Fixed EAD 2002 export crash (children_block undefined) by moving the macro to the top of the template
- Fixed invalid EAD structure: child components now nest directly in <c> instead of repeated <dsc>
- Added certainty attribute to child <unitdate> in EAD export
- Made EAD template tolerant of missing notes, creators and updated_at
