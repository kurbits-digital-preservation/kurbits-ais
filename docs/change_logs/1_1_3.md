# V 1.1.3 (2026-10-27)

# Changelog

## Added

- **Alternative name forms for agents.** New "Name forms" tab with type and date from/to, backed by a name form type vocabulary (abbreviation, former name, later name, parallel name, variant form). Name forms are searchable, shown in the agent list and search results, and included in EAC-CPF export and import.
- **Agent filter in search.** A facet listing the most common agents plus a picker for any agent. Also works without a query, listing all resources linked to the agent.
- **"Search in" scope.** Limit a search to description, notes or attachment text. Attachment text is always searchable in its own scope; the institution setting only controls whether it is included in "Everything".
- **Notes are searchable** in global search, for both resources and agents.
- **Count badges on tabs** on the resource and agent pages. Open flags are highlighted.
- **Natural sorting in the resource tree** (1, 2, 11 instead of 1, 11, 2), plus API support for manually ordering siblings.
- **Resizable filter panel in search** that remembers its width.

## Fixed

- Links between related resources are clickable, and relations are shown from both sides with the correct type (e.g. "follows" instead of "precedes").
- A relation can no longer be created twice in opposite directions.
- Clicking the same relation repeatedly now navigates as expected.

## Visual Arkiv import

- `Arkivb_Tidnamn` is imported as a "former name" name form.
- Storage unit type is imported as a metadata field. It was previously never read because of the "ö" in the tag name.
- Values previously concatenated into the description are now mapped to their proper fields: scope and content, extent, access conditions, appraisal note, placement note and disposal year.
- Updating history notes with `--force-agents` is now saved correctly.
