# Kurbits demo — demo.kurbits.net

A public demo instance of Kurbits.

## ⚠️ Data is not persistent

This instance can be **reset at any time, without notice**. Resetting wipes
**all** data

Do not:
- Store anything you need to keep
- Use it to evaluate performance with your own production-scale data
- Rely on it being available or unchanged between sessions

Do:
- Explore freely

## Logging in

The demo comes pre-loaded with one institution and three accounts, each showing
a different permission level.

| Role | Email | Password |
|---|---|---|
| System admin | `admin@kurbits.dev` | `admin` |
| Archivist | `archivist@kurbits.dev` | `archivist` |
| Read-only | `readonly@kurbits.dev` | `readonly` |

- **System admin** — full access, including Administration (institutions, users, hierarchies, vocabularies, integrations).
- **Archivist** — day-to-day cataloguing: create and edit resources, agents, locations, etc. No access to institution-level Administration settings.
- **Read-only** — browse and search only; no create, edit, or delete actions.

Log in at **[https://demo.kurbits.net](https://demo.kurbits.net)** with whichever account matches what you want to test.
